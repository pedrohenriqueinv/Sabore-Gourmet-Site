# Sabore Gourmet - Hamburgueria & Pastelaria

Site institucional e cardápio interativo com sistema integrado de pedidos via WhatsApp para a **Sabore Gourmet** (Anápolis - GO).

## 🍔 Sobre o Projeto

Aplicação web moderna desenvolvida para oferecer uma experiência de pedido rápida, fluida e intuitiva tanto no desktop quanto no mobile:

- **Cardápio Completo**: Mais de 90 itens organizados por categorias (Hambúrgueres artesanais, Pastéis especiais, Barcas gigantes, Bebidas, etc.).
- **Sistema de Carrinho Nativo**: Controle dinâmico de quantidades, opções de entrega ou retirada, observações de itens e cálculo em tempo real.
- **Checkout via WhatsApp**: Envio automático e estruturado do pedido com endereço, dados do cliente e método de pagamento (PIX, Cartão ou Dinheiro).
- **Design Responsivo & Alta Performance**: Construído com Vite, React, TypeScript e Tailwind CSS.

## 🚀 Tecnologias

- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide Icons](https://lucide.dev/)

## 🛠️ Instalação e Execução

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
